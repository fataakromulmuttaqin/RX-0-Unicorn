3. 🎯 Decision Matrix (FINAL)

✅ A+ GO (size 1.5x)

Confluence 4/4 + Regime Trending
Action: ENTER FULL POSITION, 1.5x leverage (kalau futures)
GO

✅ VALID (size 1.0x)

Confluence 3/4 + Regime Trending
Action: ENTER NORMAL, conservative SL
GO

⚠️ CAUTION (size 0.5x)

Confluence 4/4 (A+) tapi Regime Ranging
Action: boleh entry, size kecil, TP cepat
CAUTION

❌ SKIP (no trade)

Confluence 2/4 atau kurang ATAU Regime Ranging + Valid
Action: stay out, save capital buat better setup
SKIP

4. 🚦 Real-time Checklist

Sebelum Entry, Cek 5 Hal Ini:
1. Background Trending (ADX > 25)?  → kalau abu, STOP
2. Luminance breakout muncul (Lum▲ atau Lum▼)?
3. BOS/CHoCH label sesuai direction?
4. WT1 cross WT2 di zona extreme (bukan tengah)?
5. Confluence score: 3/4 = Valid, 4/4 = A+
💡 Min 4 dari 5 = ENTRY. Kalau cuma 3 dari 5, lean SKIP.
