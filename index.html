Arsitektur v0.7.0

Empat timeframe, satu keputusan

Setiap timeframe punya tanggung jawab berbeda — dari bias jangka panjang sampai timing masuk presisi. Sinyal hanya valid kalau timeframe yang lebih besar tidak menolaknya.

1D
Long-term bias
EMA 20/50 + market structure. Filter paling atas — menentukan arah besar.
→
4H
Medium bias
EMA 50/200 + market structure. Konfirmasi arah menengah sebelum turun ke setup.
→
1H
Setup
4-indicator confluence scoring berjalan di sini — jantung dari sistem.
→
15m
Entry timing
EMA 9/21 cross + RSI(7) + volume. Menentukan titik masuk presisi.
1D+4H+1H semua align → STRONG ALIGNED (eligible A+)
4H+1H sepakat, 1D netral → SOFT ALIGNED (trade diizinkan)
4H bias lemah (strength<30) → hanya entry 1H, tanpa 15m
4H vs 1H konflik, atau ketiganya konflik → NO TRADE

Kontrol Risiko Berlapis

01
Risk per trade 1–2%
Ukuran posisi dihitung dari persentase modal, bukan nominal tetap.
02
R:R minimum 1:2
TP1 = 1R, TP2 = 2R. Setup dengan risk-reward buruk otomatis dilewati.
03
Maks 3 trade/hari
Guard anti-overtrading — mencegah bot "mengejar" pasar saat volatil.
04
Daily loss limit 5%
Auto-stop kalau rugi harian tembus batas — sistem berhenti, bukan balas dendam.
05
Drawdown circuit 15%
Trading dijeda otomatis 24 jam saat drawdown menyentuh ambang ini.
06
Correlation guard
Maks 2 posisi dalam grup berkorelasi tinggi — 11 grup, 17 cross-rule.
07
Trailing stop pasca-TP1
Profit ratchet 50%: SL 1% saat +2%, 2.5% saat +5%, 5% saat +10%.
08
MTF filter wajib align
1D + 4H + 1H harus sepakat — tidak ada trade melawan tren besar.

Quick Start

Dari clone ke scan pertama

Paper trading aktif secara default — tidak ada uang sungguhan bergerak sampai kamu eksplisit mengaktifkannya nanti di Fase 7.

rx-0-unicorn — zsh
# clone & setup
$ git clone https://github.com/fataakromulmuttaqin/RX-0-Unicorn.git
$ cd RX-0-Unicorn && python3 -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt

# tarik data & scan watchlist
$ python main.py fetch --tier tier_1_major --timeframe 1h --limit 500
$ python main.py scan --timeframe 1h --min-score 3

# validasi strategi lewat backtest
$ python main.py backtest --symbol BTC/USDT --timeframe 1h --days 90

# jalankan paper trading (dry-run, $10k virtual)
$ python main.py paper start
$ python main.py paper monitor
→ 5-tier Telegram alert aktif otomatis jika TELEGRAM_BOT_TOKEN di-set
Advisory

Dari sistem yang solid ke bisnis yang profitable

Bagian ini bukan bagian dari repository asli — ini masukan saya setelah membaca seluruh arsitektur, hasil backtest, dan roadmap RX-0 Unicorn. Fokusnya: fitur yang menaikkan nilai guna, dan strategi yang menaikkan peluang ini jadi sesuatu yang bisa dipercaya orang lain untuk pakai uang sungguhan.

CATATAN

Fondasi teknisnya sudah kuat — 217 test, walk-forward backtest, correlation guard, MTF filter. Yang sering jadi pembeda antara "proyek bagus di GitHub" dan "produk yang orang percaya pakai uangnya" bukan lagi soal indikator, tapi soal transparansi track record, kontrol operasional, dan model bisnis yang jelas.

Fitur yang saya rekomendasikan

01 · Visibilitas
Dashboard web real-time
Equity curve live, heatmap confluence semua watchlist, dan posisi terbuka — bukan cuma lewat Telegram. FastAPI + chart ringan sudah cukup, tidak perlu framework berat.
02 · Kredibilitas
Public track record (read-only)
Halaman performa publik yang connect ke jurnal paper trading — sebelum minta orang bayar, biarkan mereka lihat rekam jejak apa adanya, termasuk yang rugi.
03 · Skala
Multi-user + vault API key terenkripsi
Kalau ke arah SaaS: isolasi portfolio per user, API key exchange dienkripsi terpisah, bukan disimpan flat di .env seperti sekarang.
04 · Monetisasi
Tier signal subscription
Jual akses sinyal (bukan capital management) via tier Free/Pro/Institutional — delayed signal gratis, real-time untuk yang bayar. Risiko regulasi lebih rendah dibanding kelola dana orang.
05 · Sizing
Position sizing adaptif
Ganti flat 1–2% dengan Kelly-fraction yang di-cap — mengoptimalkan compounding tanpa menaikkan risk of ruin, terutama berguna begitu Fase 7 live.
06 · Adaptasi
Re-optimasi walk-forward terjadwal
Jalankan ulang walk-forward bulanan agar parameter tidak stale — regime pasar crypto berubah lebih cepat dari yang diasumsikan strategi statis.
07 · Jangkauan
Alert multi-channel
Tambah Discord & WhatsApp Business API selain Telegram — banyak trader Indonesia lebih aktif di dua kanal itu, dan Telegram kadang diblokir jaringan korporat.
08 · Revenue tambahan
Referral ke exchange
Program afiliasi Binance/Bybit/OKX bisa jadi revenue stream dari komisi fee trading — tanpa nge-charge user langsung, cocok untuk fase awal membangun trust.
09 · Infra reuse
Backtest-as-a-service
Engine walk-forward + Monte Carlo yang sudah dibangun kuat bisa dibuka jadi API buat trader lain validasi strategi mereka sendiri — monetisasi infra yang sudah ada.

Catatan strategi paling penting

01
Perbesar sampel sebelum klaim performa dipakai keluar
Sharpe 6.02 dari 5 trade adalah sinyal awal yang menjanjikan, bukan bukti statistik. Sebelum angka ini dipakai untuk materi promosi atau menarik user/investor, jalankan backtest multi-tahun di banyak pair sampai sample size tembus ambang 30 trade yang sudah ditetapkan sendiri di STRATEGY.md.
02
Fase 7 adalah titik infleksi nilai terbesar — beri perhatian ekstra di kill switch
Auto-trade adalah lompatan dari "alat riset" ke "sistem yang menggerakkan uang sungguhan". Prioritaskan risk guard dan kill switch yang teruji berat (termasuk skenario API exchange down, koneksi putus di tengah posisi terbuka) sebelum menambah fitur lain.
03
Pilih satu model bisnis dulu, jangan coba semua sekaligus
Tools pribadi, layanan sinyal berlangganan, dan SaaS multi-user punya kebutuhan compliance & infra yang berbeda. Mulai dari satu — layanan sinyal biasanya jalur risiko regulasi paling rendah untuk memulai.
04
Perhatikan sisi legal kalau mau dikomersialkan
Repo ini berstatus "Private — All rights reserved". Begitu ada niat menjual sinyal atau akses ke publik di Indonesia, konsultasikan ke penasihat hukum terkait ketentuan Bappebti soal aset kripto & advisory trading, dan pastikan disclaimer "bukan nasihat keuangan" tercantum di setiap alert.
05
Correlation guard statis cepat basi — pertimbangkan rolling correlation
11 grup korelasi tetap itu titik awal yang bagus, tapi korelasi antar-aset crypto bisa berubah drastis dalam hitungan minggu (misal saat rotasi altcoin). Rolling correlation matrix yang dihitung ulang berkala akan lebih tahan terhadap perubahan rezim pasar.
